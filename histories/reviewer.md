- 2026-09-25: Recurring theme — docs overstate guardrails. (a) engine-core tsconfig default-injects the DOM lib despite README/decisions claiming it doesn't (probe: `document`/`window` typecheck; adding `lib:["ES2022"]` compiles clean); the boundary test does not scan for `document`/`window`/React. (b) README's 5-seed claim "stops the result from being a lucky seed" is false — all seeds are identical by construction and the sim provably cannot detect ANY loot regression (`dropChance`, `DROP_LEVEL_OFFSET`, `BAG_CAP` have zero effect on pacing). Always re-run the "would this test catch a regression?" question per subsystem.
- 2026-09-25: Unguarded tooling surfaces to watch: `sim/` has no tsconfig and is excluded from root typecheck (tsx is transpile-only; an ad-hoc `tsc --strict` was clean, but nothing enforces it), and `web/tsconfig.json` includes only `src`, so `web/tests/*` and `playwright.config.ts` are not typechecked. Also: `advance` accepts non-finite `deltaMs` and propagates NaN into `totalPlayedMs`/`damageCarry`/events; `loadGame` throws a raw TypeError on version-1 saves with a missing/null `state` (web catches it and starts fresh, so non-fatal).
